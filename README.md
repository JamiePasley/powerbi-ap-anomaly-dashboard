# powerbi-ap-anomaly-dashboard
Finance-focused Power BI dashboard analyzing AP spend, vendor concentration, and flagged transaction activity.

Interactive Power BI dashboard project focused on AP spend analysis, vendor concentration, and expense anomaly review using mock nonprofit transaction data.

## Tools Used
- Power BI
- DAX
- Excel

## Dashboard Features
- Executive summary KPI reporting
- Spend composition analysis
- Vendor concentration tracking
- Interactive month filtering
- Expense anomaly review workflows
- Conditional formatting and cross-filtering visuals

## Project Notes
This project uses mock nonprofit AP transaction data with manually identified anomaly scenarios to demonstrate exception reporting and dashboard functionality.

Future enhancements include:
- Rule-based anomaly detection
- Duplicate payment logic
- Statistical outlier analysis
- Automated transaction flagging
